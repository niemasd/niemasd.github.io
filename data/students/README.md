This directory stores student data. Each folder is a single student, and the following metadata attributes are supported (required attributes are in bold):

* **`first_name.txt`:** First Name
* **`last_name.txt`:** Last Name
* **`role.txt`:** Role
* **`start_year.txt`:** Start Year
* `end_year.txt`: End Year (defaults to current year if missing)
* `url.txt`: URL of Student's Website
* `advisor.txt`: Name of Student's Advisor
* `advisor_url.txt`: URL of Student's Advisor's Website
* `coadvisor.txt`: Name of Student's Co-Advisor
* `coadvisor_url.txt`: URL of Student's Co-Advisor's Website
